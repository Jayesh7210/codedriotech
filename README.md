# codedrio tech — Next-Gen Software & AI Engineering

Official **Coming Soon** website for **codedrio tech**, an elite software company specializing in enterprise software development, autonomous AI systems, distributed cloud architecture, and high-performance digital products.

---

## 🚀 Live Preview & Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS v4 (CSS-first engine with `@tailwindcss/vite`)
- **Typography**: Google Fonts (*Outfit*, *Plus Jakarta Sans*, *JetBrains Mono*)
- **Icons**: Lucide React + Custom SVG Brand Badges

---

## ✨ Features Included

1. **Interactive Real-Time Countdown**: Live ticking countdown timer configured for launch.
2. **Interactive Early Access Waitlist**: VIP email capture form with client-side validation and celebration feedback.
3. **Hero Architecture Visualization**: High-resolution 3D distributed architecture rendering with interactive telemetry hotspots (`/public/hero-tech.jpg`).
4. **Core Engineering Pillars**: 6 interactive capability cards with glow micro-interactions (AI, Cloud, Microservices, Web/Mobile, Big Data, Zero-Trust Security).
5. **Interactive System Terminal**: Live CLI emulation tab showing deployment logs and JSON company manifest.
6. **Early Partnership Consultation Modal**: Interactive inquiry form for clients, founders, and enterprises to submit project requirements before launch.
7. **Production Tested**: 0 lint errors, fast 60fps animations, fully responsive across desktop, tablet, and mobile.
